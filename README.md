# Ohm's Law and Power Calculator

## What it does
This Python program calculates voltage, current, resistance and electrical power using basic electrical formulas. It uses a menu so the user can choose a calculation and continue using the program until they decide to quit.

## How to run it
Install Python 3, save the code as `ohms_law.py`, open a terminal in the project folder, and run:

```bash
python ohms_law.py
```

## My own twist
I added a calculation history feature. It stores successful results during the current session and allows the user to view them later by selecting option 5.
